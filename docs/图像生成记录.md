# 小树人图像生成记录

本套六张图片通过内置 image_gen 工具生成，已保存至 `public/assets/`，现有组件直接读取。

## 官方参考

参考来自南方科技大学官网《2022 年 8–9 月校园文化月报》，PDF 第 7 页（印刷页 10–11）的树仁九周年海报。原海报称角色为「树小仁」。

- [官方来源](https://sustech.edu.cn/uploads/files/2022/10/13113916_93555.pdf)
- 本地原图：`imagegen-references/shuxiaoren-official-2022.jpg`（从官方 PDF 无损提取的嵌入图）
- 原图仅作角色参考，插画为 AI 绘制的博物画风格衍生版本，不是官方发布的原画。

保留官方的大圆瓣树冠、小脸、短身体、叶片领子和斜挎包；转译成铜版线描与淡水彩。后续动作同时参考官方海报与首张成稿，保持同一角色。未使用最初仅按文字生成的草稿。

## 成品

| 文件 | 像素尺寸 | 用途 |
|---|---|---|
| `mascot-cheer.png` | 1024×1024 | 收录成功 |
| `mascot-empty.png` | 1024×1024 | 阅读等待、通用空状态 |
| `mascot-search.png` | 1024×1024 | 放大镜检索 |

生成后仅规范导出尺寸。迷路图通过 image_gen 删除了意外出现的问号；封面通过 image_gen 扩大了左侧留白。完整实际提示词（包括修订）保存在 `imagegen-prompts.json`。

原有物种图版、校园照片、院徽与 `/credits` 页面保留。
