| 用途 | 位置 | 来源 |
|---|---|---|
| 24 种校园动植物的图版（同学的默认形象） | `public/assets/species/*.jpg` | 维基共享资源上的公有领域博物画：Blanco《菲律宾植物志》（1880 年代）、Boym《中国植物志》（1656）、Hardwicke、Keulemans、Naumann、久保俊满等 |

## 二、需要 GPT 生成的：吉祥物「小树人」插画（6 张，选做）

这 6 个位置缺图时会直接留空，不影响使用。生成后按文件名放进 `public/assets/`：

| 文件名 | 出现位置 |
|---|---|
| `mascot-cheer.png` | 主页上传成功、盖「收录」章的时刻 |
| `mascot-empty.png` | 通用空状态（收藏为空、主页不存在） |
| `mascot-search.png` | 检索没有结果 |
| `mascot-megaphone.png` | 活动大厅没有招募 |
| `mascot-lost.png` | 404 页面 |
| `og-cover.png`（1200×630） | 微信 / QQ 转发时的链接封面 |

### 风格要求（重要）

网站现在的视觉是一本「校园图鉴」，所以小树人也要画成**图鉴里的一幅博物画**，而不是扁平的卡通贴纸。否则它会和旁边的老图版格格不入。

**使用方法**：先上传官方小树人原图作为参考，再粘贴下面的「通用前缀」，最后接上具体动作。

### 通用前缀（每次都先粘贴）

```
请参考我上传的南方科技大学树仁书院吉祥物「小树人」，保持角色的造型特征：
蓬松云朵状的青绿色树冠（#509C7C），右上方一小枝两片叶子；浅木色的圆润身体（#ECC498），腿和肚子上有木纹旋涡；大而亮的棕色眼睛、粉色腮红；脖子一圈深青色叶片领子；斜挎卡其色小书包。

画风：画成一幅 19 世纪手工上色的博物学图版（参考 Curtis's Botanical Magazine、Blanco《菲律宾植物志》的铜版画 + 水彩手工上色）。
- 细密的铜版线条、交叉排线表现明暗，再用透明的水彩淡淡上色；颜色克制、略微褪色。
- 背景是干净的米白色旧纸（接近 #F3EFE4），不要纸张脏污和折痕。
- 主体居中，四周留白充足；可以像标本图一样在角色脚下画一小片地面或落叶。
- 不要任何文字、标签、签名、水印、边框。
- 输出 PNG，1024×1024。
```

### 1. mascot-cheer.png：被「收录」的那一刻

```
小树人端正地站着，双手捧着一本打开的小册子举在胸前，像在展示自己刚被收录进图鉴的那一页，脸上是满足又有点害羞的笑。脚下是一小片青草和两片落下的木棉花瓣。
```

### 2. mascot-empty.png：安静地等

```
小树人坐在一截小树桩上，低头翻看一本书，书包放在脚边。姿态放松，像在等朋友来。整体构图偏低，留出上方大片空白。
```

### 3. mascot-search.png：拿放大镜找

```
小树人侧身弯腰，手持一个黄铜边框的放大镜，认真地观察地上的一片叶子，像博物学家在野外考察。叶片与放大镜都用精细的铜版线条画出。
```

### 4. mascot-megaphone.png：贴招募启事

```
小树人踮着脚，把一张空白的小纸片（纸上不要有字）用图钉按在一块小木板上，另一只手还拿着几张没贴的纸。神情认真。
```

### 5. mascot-lost.png：迷路

```
小树人站在两条分岔的小路中间，一只手挠着树冠，另一只手拿着一张展开的地图（地图上只画虚线路径，不要文字），神情困惑。脚边立着一个空白的木路牌。
```

### 6. og-cover.png：链接封面（1200×630）

```
横版 1200×630。左侧约 55% 为干净的米白旧纸留白（用于后期叠加标题文字）。右侧是一组像图鉴扉页一样排列的博物画：中央是小树人（按上面的风格），周围环绕着木棉花枝、荔枝果枝、一只白鹭、一只翠鸟，都是 19 世纪手工上色铜版画风格，彼此不重叠，排列疏朗。不要任何文字。
```

生成封面后，可以用任意设计软件在左侧叠加两行字：「树仁搭子图鉴」（抖音美好体）和「南方科技大学树仁书院 · 学习搭子广场」（MiSans）。

## 三、选做：让同物种的同学也有不同的图版

现在同一种动植物只有一幅图版，所以两位「白鹭」同学的形象是一样的（靠编号区分）。如果想让每个人都不一样，可以继续在维基共享资源上找同物种的其他公有领域图版，按 `slug-2.jpg`、`slug-3.jpg` 命名放进 `public/assets/species/`，再告诉开发同学在 `Plate` 组件里按编号轮换。**不建议用 GPT 生成物种图版**：老图版的真实感正是这套设计不像 AI 的原因。
