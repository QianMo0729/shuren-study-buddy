# 学习工具合作福利 MVP

本次增加学习工具福利入口、Xmind 活动页与登记、MarginNote 活动页与兑换码分配。沿用现有校园账号和 SQLite 数据库，不依赖外部表单服务。未接入飞书、腾讯文档或 Notion 自动同步，名单通过专用网页共享。

## 本地查看

要求 Node.js 22.13 或以上，沿用项目的依赖安装与开发方式：

```bash
npm ci --no-audit --no-fund
npm run dev
```

在浏览器打开：

| 路径 | 内容 |
| --- | --- |
| `http://localhost:5173/benefits` | 合作福利专区，公开可浏览 |
| `http://localhost:5173/benefits/xmind` | Xmind 功能、视频、模板和领取登记 |
| `http://localhost:5173/benefits/marginnote` | MarginNote 介绍、示例和兑换码领取 |
| `http://localhost:5173/benefits/records` | Xmind 工作人员名单页 |

首页及登录后的「今天」页均有入口：「品牌合作」一节（标注「广告」），每个福利是一张票据，左侧票根写数量，右侧写品牌、领取条件和剩余名额。手机上两张票叠放，每 5 秒自动轮换一次，也可以左右滑动或点下方圆点翻页（系统开启「减少动态效果」时不自动轮换）；宽屏并排显示。已领取的票方框打勾、票根多一个检票孔并盖「已领」章。活动内容公开展示；领取需要先登录现有校园账号，无需发布个人主页或填写匹配问卷。不要为了预览在已有数据上运行 `npm run seed`。

## Xmind 登记与名单共享

0. **登记默认关闭**，由网站管理员在管理后台顶部的「Xmind 点数登记」开关手动开放，也可以随时暂停（操作记入处理记录）。未开放时活动内容照常可以浏览，页面显示「即将开放」，不计时，服务器也拒绝发放浏览凭证和登记。
1. 登记开放后，登录的同学进入 Xmind 页，向服务器取得绑定当前账号的短时浏览凭证，30 秒计时从这时开始。
2. 只有在浏览活动时才计时：福利页面开着并且在屏幕上，或者刚从福利页面点开了模板、视频、指南（它们在新标签页打开）。去了网站的其他页面、切到别的应用或关掉页面，计时暂停，回来后接着之前的秒数继续；在几个福利页面之间跳转或刷新页面不会重来（已累计的秒数保存在本标签页的 `sessionStorage` 中）。服务器另外检查凭证所属账号、从取得凭证起至少过了 30 秒，以及一小时有效期；凭证快过期时页面会自动换新并重新计时。
3. 所有福利页面右下角有一个倒计时小球，显示剩余秒数；时间到了变成「领取」，点开就是登记表单。活动页上的按钮打开的是同一个表单。
4. 填写本人 Xmind 账号绑定手机号，并明确同意发放用途后提交。粘贴带 `+86`、空格或短横线的号码会自动整理成 11 位。只做格式检查，不发送短信、不核验 Xmind 账号、不按手机号去重。
5. **每个站内账号只能登记一次**（`benefit_xmind.user_id` 唯一）。同一账号再次提交相同号码视为重试，返回原登记，不额外占名额；提交不同号码会被拒绝，需由管理员删除原登记后重新登记。不同账号可以提交相同号码。
6. 服务器通过 SQLite `BEGIN IMMEDIATE` 事务串行检查 200 条上限并写入，防止多个 API 进程超额登记。
7. 登记后活动页显示「已登记」、隐去中间四位的号码和提交时间，再次打开也能看到；名单不含充值状态，不表示实时到账。

更正与删除：网站管理员可在名单页逐条删除登记，删除后空出一个名额，该同学可重新登记正确的号码；持口令的合作方人员只能查看和导出。同学注销账号时，本站保存的登记随之删除。已导出的名单不会自动更新，需另行告知 Xmind。登记的保存期限尚未确定，确定后应补上到期清理并写入隐私政策。

网站管理员登录后可以直接查看名单。为 Xmind 工作人员开放访问时，在服务器的 `.env` 中配置至少 32 位随机字符的 `XMIND_LIST_TOKEN`，重启 API 后，将口令和 `/benefits/records` 页面地址通过双方约定的私密渠道提供给指定人员。

该口令只授权读取和导出 Xmind 名单，不授予其他管理权限。口令不写在 URL、不持久化到浏览器存储。名单页在可见状态下每 5 秒读取一次，显示最近成功更新时间；可导出包含手机号、北京时间和序号的 CSV。未配置口令时仅管理员可访问，审核员和普通学生均不可访问。

API：

- `GET /api/benefits/status`：仅公开活动状态与剩余数量（`xmind.open` 表示登记是否开放）。
- `PUT /api/benefits/xmind/open`：仅管理员，提交 `open: true / false` 开放或暂停登记。
- `POST /api/benefits/xmind/visit`：已登录用户取得浏览凭证。
- `POST /api/benefits/xmind/register`：提交 `token`、`phone`、`consent: true`。
- `GET /api/benefits/xmind/mine`：已登录用户查看自己的登记（号码隐去中间四位）。
- `DELETE /api/benefits/xmind/registrations/:id`：仅管理员，删除一条登记。
- `GET /api/benefits/xmind/registrations`：管理员会话或 `Authorization: Bearer <口令>`，返回名单。
- 同一路径加 `?format=csv` 导出名单。

正式开放前需确认活动截止时间、到账安排、点数有效期及登记保存期限。部署后登记保持关闭，准备好收集名单后由管理员在后台开放；没有定时自动开放或截止的功能。

## MarginNote 兑换码

真实兑换码只导入服务器数据库，不提交 Git，也不放进公开静态文件。素材包中的 CSV 第一列为兑换码；先在服务器受限目录解压，再运行：

```bash
npm run benefits:import -- /绝对路径/树仁第一批OfferCode（100 个）.csv
```

导入可重复执行，相同码自动跳过，命令只显示导入数量。若提示格式错误，不要将完整兑换码名单粘贴到公开 issue 或 PR。

合作方确认完整兑换、自动续订与取消说明后，把面向用户的说明填入服务端 `.env` 的 `MARGINNOTE_RENEWAL_TERMS` 并重启 API。在此之前页面可浏览，但领取接口保持关闭，不用素材中的待确认价格代替正式条款。

每个站内账号分配一个码，数据库事务和唯一约束保证不重复分配；用户再次打开可查看自己的原码。站内账号注销后，已分配的码不会重新发给别人。2027 年 2 月 12 日北京时间结束后不再发新码。站内账号限制不能保证一名学生只持有一个账号，也不能替代 Apple 的兑换资格判断。

活动状态接口返回 `marginnote.phase`（`upcoming`、`open`、`exhausted`、`ended`），入口、福利专区和详情页统一展示未开放、已开放、已领完或已结束。各页面共用一份状态，进入页面或回到页面时超过 30 秒才重新读取，不做定时轮询。未开放时，访客可查看学习示例和兑换条件，不显示领取勾选框或登录领取按钮；状态加载失败时显示读取失败，不将其误报成未开放。

宣传片原文件约 293 MB，MVP 使用提供的截图，不将大视频直接加入仓库。截图已压缩为 WebP（宽 1400 像素，四张合计约 470 KB；原始 PNG 合计约 6.4 MB）。正式版如需视频，先提供适合网页播放的压缩版本或托管地址。页面中的 Xmind 视频直接链接官方哔哩哔哩视频，避免加载第三方嵌入播放器。

## 验证

```bash
npm run build
node --import tsx --test --test-isolation=none tests/benefits.test.ts
node --import tsx --test --test-isolation=none --test-name-pattern='partner source|the dev server listens' tests/dev-server.test.ts
```

新增用例覆盖：登记开关（默认关闭、仅管理员可开关、关闭后已打开的页面也不能登记）、30 秒等待、凭证过期与账号绑定、手机号格式和同意用途、重复提交、一个账号只占一个名额、200 条上限、管理员删除后可更正、注销账号清除登记、兑换码分配与账号隔离、注销后不回收旧码、名单授权与 CSV 导出。原有开发服务器测试继续保留；当前受限执行环境不能监听网络端口，完整 HTTP 回归及浏览器检查需在可启动服务的 WSL 环境运行。

素材 ZIP 含尚未分配的真实兑换码，原始 ZIP、CSV、DOCX 已在开发服务器静态访问规则中禁用。公开页面只使用从素材中提取的指定图片。

## 入口品牌图形来源

福利专区及产品详情页统一使用两家产品的官网 Logo，保持原始比例和颜色。（首页和「今天」页的入口是票据样式，只写品牌名称，不放 Logo。）详情页在首屏、领取区和页尾展示对应品牌，首屏使用更大尺寸；白色底板保证深色主题下仍可识别品牌原图。

Logo 文件保存在 `public/partners/logos/`，随站点一起发布，页面不再向合作方的服务器发请求：

- `xmind.svg`：取自 Xmind [官方设计资源](https://xmind.cn/design-resources/)页提供的 [Logo SVG](https://assets.xmind.cn/www/assets/images/new-xmind-logo-dark-60f56e9142.svg)。
- `marginnote.png`：取自 MarginNote 5 [官网](https://www.marginnote.com/en/index.html)页脚使用的 [MN5 Logo PNG](https://www.marginnote.com/assets/mn5/mn5-logo.png)。

品牌方提供正式的 Logo 文件后，替换这两个文件即可。
