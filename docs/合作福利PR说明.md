## 问题与改动

为树仁学习搭子接入 Xmind 和 MarginNote 合作福利。首页及「今天」页增加品牌合作入口，公开活动页展示合作方提供的功能介绍、官方视频链接、学习模板与笔记示例。

Xmind 用户登录后浏览满 30 秒，可提交本人账号绑定手机号；服务器验证短时浏览凭证、明确授权及 200 条登记上限。每个站内账号只能登记一次，重试不会额外占名额，不按手机号去重、不做短信验证。计时按实际经过的时间计算，切换标签页、打开模板链接或去别的福利页都不会中断；福利页面右下角的倒计时小球显示剩余秒数，时间到了点开即可登记。管理员和持有专用口令的 Xmind 工作人员可在专用名单页查看、自动刷新及导出 CSV，无需网站管理权限；删除登记仅限管理员。

MarginNote 兑换码由服务端导入并通过事务分配，每个站内账号保留一个码，已用码不会因账号注销重新发放。续订条款未确认前默认关闭领取。真实兑换码、活动原始附件和 293 MB 宣传片不进入代码仓库。

## 验证

- `npm run build`：TypeScript 检查及生产构建。
- `node --import tsx --test --test-isolation=none tests/benefits.test.ts`：领取规则、名额、重试、兑换码及名单权限检查。
- 开发服务器配置检查：验证活动原始附件不可直接下载。
- 当前执行环境无法监听本地端口，完整 HTTP 回归和手机/桌面浏览器检查尚未完成，合并前需在本地复核。
